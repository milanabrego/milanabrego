## Sobre mí

Estudiante en la **Universidad Tecnológica de Panamá (UTP)** y desarrollador web.
Me enfoco en la **ciberseguridad**: construyo sitios y sistemas pensando en la seguridad desde el primer día, no como un parche al final.

- Desarrollo sitios y sistemas web para negocios en Panamá.

## Cómo trabajo la seguridad

- **Secretos fuera del repositorio:** las claves y contraseñas viven en variables de entorno, nunca en el código.
- **Validación en el servidor:** lo importante se comprueba en el backend, no solo en el navegador.
- **Cabeceras de seguridad y CSP** configuradas desde el inicio.
- **Pruebas antes de cada commit** para no subir código roto.
